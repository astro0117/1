# 增强型文件系统 - 操作系统大作业

一个完整的模拟文件系统实现，集成了三大扩展功能：
1. **事务日志与崩溃恢复** - 保证操作原子性，系统崩溃后可恢复
2. **文件版本控制** - 自动保存文件历史版本，支持版本对比和恢复
3. **文件加密/压缩** - 透明加密解密，可选压缩存储

## 功能特性

### ✅ 基础功能
- 文件创建、删除、打开、关闭、读取、写入
- 目录创建、删除、列表
- 多用户支持（登录、登出、权限控制）
- 文件权限管理（chmod）
- 文件信息查看（stat）
- 文件复制、移动

### 🛡️ 事务日志与崩溃恢复
- Write-Ahead Logging (WAL) 保证操作原子性
- 系统崩溃后自动恢复未完成的操作
- 手动触发恢复功能
- 事务提交和回滚

### 📚 文件版本控制
- 自动保存文件历史版本（最多10个）
- 版本列表查看
- 任意版本恢复
- 版本差异比较
- 版本导出功能

### 🔐 文件加密/压缩
- 透明加密解密（使用Fernet加密）
- 可选压缩存储（使用zlib）
- 独立控制每个文件的加密/压缩状态
- 加密密钥管理
